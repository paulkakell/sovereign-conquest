# Getting help

Use [Q&A](https://github.com/paulkakell/sovereign-conquest/discussions/categories/q-a)
for gameplay, installation, and server questions. Include your version, what you
tried, and the relevant sanitized error. Mark the helpful response as the answer.

Use the [issue chooser](https://github.com/paulkakell/sovereign-conquest/issues/new/choose)
for reproducible defects, concrete feature requests, and documentation corrections.
Explore early proposals in [Ideas](https://github.com/paulkakell/sovereign-conquest/discussions/categories/ideas).

Report vulnerabilities privately using the [security policy](SECURITY.md).
Never post credentials, complete environment files, or private player data.

See the [community guide](docs/COMMUNITY.md) for category examples, funding
configuration, and maintainer setup details. Community support has no guaranteed
response time.
